#Анализ поставок лекарственных препаратов

Стек: Power BI, MySQL

#Описание проекта
Анализ предприятия по поставкам лекарственных препаратов "Микстура"
Цель: определить динамику заказов, выявить самых прибыльных клиентов и препараты с максимальной выручкой.

#Результаты
- Общая выручка: 94 млн. руб.
- Выявлено топ-5 препаратов по вырчуке.
- Определен пик спроса на препараты в периоде с апреля по май.

#Инструменты
- MySQL: построение и заполнение базы данных
- Power BI: построение визуализации и дашборда.

#Дашборд
'Микстура_дашборд.pbix' - дашборд. Для ознакомления скачайте файл и откройте в программе Power BI.
Визуализации полностью интерактивны. Допустны фильтры слева по названию препарата и дате заказа.
